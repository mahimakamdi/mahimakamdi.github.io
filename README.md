# Mahima Kamdi — DevOps Portfolio

A dark, cloud/DevOps-focused personal portfolio built as a lightweight static website.

## Run locally

Open `index.html` directly in a browser, or use any simple local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy free

### GitHub Pages
1. Create a GitHub repository named `mahimakamdi.github.io`.
2. Upload everything inside this folder.
3. In GitHub: Settings → Pages → deploy from the `main` branch.
4. Your portfolio will be available at `https://mahimakamdi.github.io`.

### Other free hosting
The same folder can be deployed to Netlify, Vercel, or an AWS S3 static website/CloudFront setup.

## Included
- Responsive DevOps-focused landing page
- Highlighted profile image
- About, tech stack, projects, experience and certification sections
- Resume PDF
- GitHub / LinkedIn / email links
- Animated visual background and subtle scroll reveals

## Personalize
Edit `index.html` for content and `style.css` for colors, spacing and visual design.
